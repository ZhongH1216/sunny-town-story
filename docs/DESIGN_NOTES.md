# demo.4 的玩法与美术方向

本轮根据玩家“单调、画面不好看、帧率偏低”的反馈，把改进集中在布局选择、聚落观感和绘制效率。玩家明确喜欢 ISLANDERS 的画风。

## 参考与转化

- [ISLANDERS（开发者 / 发行方商店页）](https://store.steampowered.com/app/1046030/ISLANDERS/)：参考低多边形岛屿的清晰轮廓与建筑邻近带来的策略。本项目使用原创程序几何、奶油墙面与少量屋顶配色，并用四种街区组合连接现有道路、住宅和公共服务。
- [Townscaper（开发者 / 发行方商店页）](https://store.steampowered.com/app/1291340/Townscaper/)：参考建筑组合后形成聚落的视觉反馈，以及安静欣赏自己作品的体验。本项目加入可暂停时间、隐藏界面、平移缩放的观景模式。
- [Dorfromantik（开发者网站）](https://www.toukana.com/dorfromantik/)：参考可读的短期布局目标与舒缓建设节奏。本项目把“下一颗星还缺什么”直接写在街区卡片和建造预览中。

以上作为设计参考，游戏代码、模型和素材继续在本仓库维护。它们并非本项目的依赖，也不代表这些作品参与或认可本项目。

## 街区灵感

花园里巷、商店街、书香街坊与匠人街区各有 1–3 星。条件使用横竖格距、已接道路的建筑和工业隔离，因此同样的预算可以产生不同的布局结果。

每种主题只计算全城最好的一处，游客收入合计最多 ¥250 / 周，随实际布局升降。每类第一次成形可领取 ¥600；领取记录保存在独立存档字段中。计算、渲染和预览只展示结果，资金在周结算或实际领取操作中变化。

布局引导完全自愿。原有故事、来信、祭典和四季活动继续提供不同长度的目标；玩家可以先完成一条舒服的街巷，再决定是否扩张。

## 视觉与运行原则

建筑以体块、屋顶和少量清楚的门窗区分功能。场景使用较大的草地与海面色块，削弱细密网格和重复小纹理，让聚落本身更容易被看见。

静态几何尽量合批，共享模板与材质；道路和移动体减少独立绘制对象。保留需要反馈的建造动画，静止建筑不持续执行装饰动画。测试将记录绘制调用、几何资源和帧内耗时，并注明测试后端。

观景模式是临时状态：进入时暂停，退出时恢复进入前的暂停状态；平移缩放可用，建造和经营快捷键被阻止。它不改变存档中的建筑或故事进度。
