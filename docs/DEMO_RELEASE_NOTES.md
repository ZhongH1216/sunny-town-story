## 开始试玩

1. 完整解压 `sunny-town-story-1.0.0-demo.4.1.zip`，不要直接在压缩包内运行。
2. 电脑需要 **Python 3.10+** 和支持 WebGL 2 的桌面浏览器。当前以 Windows 为主要验收平台。
3. 双击 `start-sunny-town.bat`，浏览器会打开 `http://127.0.0.1:8765/`。
4. 游玩期间保留服务器窗口。结束后按 `Ctrl+C`，或运行 `stop-sunny-town.bat`。

发布包包含 Three.js 与游戏素材，不需要 Node.js、npm 或 Conda，游玩本身无需联网。Python 未随包分发，可从 [Python 官方网站](https://www.python.org/downloads/) 安装。源码开发者需要先执行 `npm ci`，试玩 ZIP 不需要这一步。

macOS / Linux 可在解压目录尝试 `python3 app.py`，再打开本地地址；其他系统尚未实机验收。

## 操作与存档

选择工具后点击地图建造，移动鼠标查看预览与失败原因；拖拽平移，滚轮缩放，`C` 返回中心。道路工具下按住 `Shift` 拖拽可连续铺路。空格暂停，`V` 调速，`U` 或 `Ctrl+Z` 撤销本周建造，周结算后撤销记录清空。底部 `?` 和 `i` 提供快捷键与建设手册。

地图「交通」图层用绿色表示畅通、红色表示拥堵；「服务」图层用绿色表示水电完整、红色表示有缺口。建筑需要贴近道路，覆盖还受道路可达与服务容量影响。

小镇自动保存在当前浏览器，也可手动保存。顶栏「存档管理」支持 JSON 导出 / 导入。存档格式仍为 v3，可选 `life` 字段记录活动、项目和收藏；demo.4 新增独立可选 `neighborhoods` 字段记录主题领奖与引导。兼容旧 v1 / v2 / v3，缺少对应字段时使用安全的空状态。请用同一浏览器、同一地址和端口继续；更换端口、隐私窗口或清除浏览器数据会影响原存档。开启新故事或更换电脑前可先导出备份。

## 帧率与资源控制

「存档管理 → 画面与耗电」对新玩家默认标准 **30 帧**，可选省电 24 帧或流畅 60 帧，已有存档中的有效画面偏好继续保留。暂停时渲染上限为 **10 帧**，菜单 / 阻塞弹层为 **1 帧**；页面隐藏时停止绘制与模拟并暂停音乐，返回后恢复。以上是渲染上限，实际帧率取决于设备、浏览器和小镇规模。

324 块草地合并绘制；道路按连接状态变化更新，移动体复用，替换的局部几何资源会释放。路由缓存最多 2,048 项，效果粒子最多 96 个。界面取消大面积背景模糊。这些是运行策略与资源限制，不代表已经测得所有电脑的 CPU 降幅。

## 画面连接中断时

如果浏览器丢失图形连接，游戏会停止渲染、模拟和音频，并显示恢复面板。可以尝试「恢复画面」，或先导出备份，再选择「保存后刷新」。恢复成功后可以继续游戏；如果驱动仍无法创建画面，先保留导出的存档，再检查浏览器与图形环境。

这项保护用于保留进度和提供恢复入口，不代表已经解决所有显卡驱动或浏览器兼容问题。

### demo.3 验证后端与限制

本机 Chromium 默认 ANGLE 后端在启动时报告 `Creation of StagingBuffer's SharedImage failed`，并发生图形连接丢失。单页软件 ANGLE 可以正常运行，因此本轮自动化通过环境变量 `SUNNY_TOWN_SOFTWARE_WEBGL=1` 显式选择 `--use-angle=swiftshader`。这一选择仅用于测试后端，当时交付游戏不强制使用软件渲染，默认省电档；demo.4 新玩家默认改为标准 30 帧。

软件后端的通过结果不能证明默认硬件后端问题已经解决，也不能用于宣称实机 CPU 降幅或所有硬件无错误。本轮如实保留该机器的硬件后端异常限制；其他设备、驱动和长时间人工游玩仍需反馈。

地图固定为 **18 × 18**，桌面 16:9 优先，不提供移动端适配、地图扩张、随机地图、地形编辑、多人联机或原生安装器。Python 3.10+ 是明确运行要求。

## 启动排障与反馈

- 缺少 Python：安装 Python 3.10+，或将 `SUNNY_TOWN_PYTHON` 设为解释器完整路径。
- 缺少游戏文件：重新完整解压 ZIP；不要只复制启动脚本。
- 端口占用：先关闭已有游戏服务，或执行 `python app.py --port 8766` 并打开对应地址。不同端口使用不同本地存档空间。
- 地图无法显示：检查浏览器 WebGL 2 与硬件加速设置，保持省电模式再观察。
- 浏览器关闭后服务仍在：在服务器窗口按 `Ctrl+C`，或运行停止脚本；停止脚本只向本目录记录的游戏服务发送关闭请求。
