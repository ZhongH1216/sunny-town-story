把公园留在家门口，让商店围着广场亮起灯，再为远离住宅的手作工坊留一条街。

这是 **阳光小镇物语 1.0.0-demo.4.1「街区灵感」** 试玩预发布。验证记录见下文；可下载附件以本页实际显示的列表为准。

## 本轮新增

- **四种街区组合**：花园里巷、商店街、书香街坊、匠人街区，让建筑距离、道路和工业隔离影响 1–3 星布局。每主题只计最好的一处，游客收入分别为 ¥35 / ¥55 / ¥75 每周，全城最多 ¥250 / 周。
- **一次灵感奖励**：每主题首次合格可手动领取 ¥600，固定领取记录随存档保留，重建不能反复领取。布局引导免费，不限制建设。
- **摆下去之前就能判断**：建造预览提示组合升降星与游客收入变化；完整三星规则收在可展开说明中。
- **原创低多边形重制**：借鉴 ISLANDERS 的空间组合思路与视觉方向，重新制作海岛、建筑、树木与港湾的程序几何，并合并静态细节绘制。
- **停下来看看小镇**：`P` 进入观景模式，保留拖拽与缩放；`P` 或 `Esc` 返回，恢复进入前的暂停状态。
- **新的画面默认值**：新玩家使用 30 帧标准档，24 / 60 帧仍可选；已有存档的有效偏好继续保留，后台停止绘制、模拟与音乐。
- **读档立即刷新**：暂停时读入城镇，街区星级与资金等界面也立即更新，无需等待下一周。

三种故事、9 封居民来信、4 份市政提案、春日祭典、四季活动与 3 项永久社区项目继续保留。绘制优化的实测方法与限制见[性能报告](https://github.com/ZhongH1216/sunny-town-story/blob/main/docs/PERFORMANCE.md)。

## 下载与启动

附件发布后，下载 **`sunny-town-story-1.0.0-demo.4.1.zip`**，完整解压并双击 `start-sunny-town.bat`。电脑需要 **Python 3.10+** 和支持 **WebGL 2** 的桌面浏览器；Python 不随包提供。游戏依赖与素材已包含，玩家无需 Node.js / npm / Conda，准备好运行环境后可离线游玩。

GitHub 自动生成的 “Source code” 是开发源码包，运行前还需安装开发依赖。试玩附件的 `.sha256` 可用于核对 ZIP 完整性。

## 存档与试玩范围

存档版本保持 v3，兼容旧 v1 / v2 / v3；街区记录使用新增的可选 `neighborhoods` 字段。换故事、设备或清理浏览器数据前，请先导出 JSON 备份。

当前为 **18 × 18 固定地图、桌面键鼠试玩**，没有移动端适配或原生安装器；macOS / Linux 尚未完成实机验收。美术为本项目程序几何与素材，并未分发 ISLANDERS 的游戏资产。

## 验证状态

2026-09-16 本地验收覆盖 **84 项 Playwright 任务（69 项浏览器回归 + 15 项街区纯计算）**、**3 项美术几何 / 资源测试**、**9 项服务 / 启动代理测试**。干净源码离线依赖安装和环境检查通过；完整回归中帧率采样用例按真实时长修正后，5 项性能专项复验通过，84 项均有通过结果。实际 ZIP 解压后的 78 个文件与哈希清单全部一致；正常入口启程、保存、推进和读档通过，没有页面异常或失败资源。详细分段记录见完整发布说明。三种故事均使用正常收入完成祭典，没有额外注资。

本轮浏览器验收显式使用 SwiftShader 软件渲染，该结果不能证明本机默认 ANGLE 后端的兼容问题已经解决，也不能推及所有设备。游戏不强制软件渲染。GitHub 发布工作流只有在 Windows 全量测试与实际 ZIP 验证通过后，才会上传并公开试玩附件。
